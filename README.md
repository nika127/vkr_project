# Arbat Gold Premium Mobile App

Prototype Flutter structure for the "Арбат Голд Премиум" mobile app. This repository provides a Clean Architecture layout, placeholder screens, and domain entities aligned with the graduation project requirements.

## Quick start
1. Install the Flutter SDK: https://flutter.dev/docs/get-started/install
2. Generate platform folders (Android/iOS):
   ```bash
   ./scripts/bootstrap_flutter.sh
   ```
3. Fetch dependencies:
   ```bash
   flutter pub get
   ```
4. Run the app:
   ```bash
   flutter run
   ```

The current build runs against an in-memory mock data source so the UI is functional without Firebase.

## Firebase setup (ready for drop-in configuration)
The codebase already includes Firebase dependencies and repositories. Once you add Firebase
configuration files, the app will automatically switch from mock data to Firestore.

1. Install FlutterFire CLI and configure the project:
   ```bash
   dart pub global activate flutterfire_cli
   flutterfire configure
   ```
2. Add the generated config files:
   - `android/app/google-services.json`
   - `ios/Runner/GoogleService-Info.plist`
3. Replace the placeholder values in `lib/firebase_options.dart` (or overwrite it with the file
   generated by FlutterFire).

If Firebase is not configured, the app stays on mock data, so you can keep working without
breaking the UI.

## Structure
- `lib/domain`: entities, repository interfaces, and use cases
- `lib/data`: data models and data source stubs
- `lib/presentation`: UI shell and feature screens
